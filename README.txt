CÓMO PUBLICAR EN GITHUB PAGES
1. Crea un repositorio nuevo en GitHub (por ejemplo, soltix).
2. Sube el contenido DE ESTA CARPETA a la raíz del repositorio:
   index.html y la carpeta assets (no subas solo el archivo ZIP).
3. En Settings > Pages, en Build and deployment, selecciona
   Deploy from a branch y la rama main, carpeta / (root). Guarda.
4. Espera a que GitHub indique la URL pública de tu página.

Para probar localmente, abre index.html en tu navegador.
